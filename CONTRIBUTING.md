# Contributing to Novae Universe

Thank you for your interest in Novae Universe. This is an indie open source
project maintained by a single developer. Contributions are welcome within the
rules below.

## How to Contribute

1. Fork the repository
2. Create a descriptive branch:
   - `feat/novae-gate-animation`
   - `fix/novae-star-shader-dark`
   - `docs/setup-oauth-guide`
3. Make your changes
4. Open a Pull Request with a clear description

## What Is Welcome

- Bug fixes
- Performance improvements on the frontend or backend
- New Novae World types (biomes, shaders)
- Improvements to the Novae HUD or Novae Map
- Accessibility improvements
- Documentation and translations

## What Will Not Be Accepted

- Changes to the license or contribution terms
- Features that conflict with the project's direction
- PRs without description or context
- Heavy dependencies without clear justification
- Any change that exposes credentials or breaks security

## Branch Strategy

| Branch   | Purpose                                      |
| -------- | -------------------------------------------- |
| `main`   | Production — protected, owner merges only    |
| `dev`    | Active development                           |
| `feat/*` | New features                                 |
| `fix/*`  | Bug fixes                                    |
| `docs/*` | Documentation                                |
