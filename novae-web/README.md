# Novae Universe Web

React, Three.js and React Three Fiber frontend for Novae Universe.

## Setup

```bash
cp .env.example .env
npm install
npm run dev
```

Set `NOVAE_API_URL` to the public URL of Novae API.

## Concepts

- Novae Galaxy is the explorable scene.
- Novae Stars represent developers.
- Novae Worlds represent repositories.
- Novae Gates connect regions.
- Novae Ship is controlled by the player.
- Novae HUD and Novae Map expose navigation data.
